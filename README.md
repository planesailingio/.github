# .github

Organisation-level defaults for [planesailingio](https://github.com/planesailingio).

- [`profile/README.md`](profile/README.md) is the organisation landing page shown at [github.com/planesailingio](https://github.com/planesailingio).
- [`profile/banner.svg`](profile/banner.svg) is the hero banner it embeds, referenced by raw URL from the `master` branch.

Badges are served by [shields.io](https://shields.io) and read release, CI and licence state live from each repository, so nothing here needs updating when a project ships a new version.
